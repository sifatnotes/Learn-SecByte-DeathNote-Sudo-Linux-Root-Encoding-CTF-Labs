# Learn SecByte DeathNote, Sudo, Root & Encoding CTF Labs

## Introduction

This repository organizes hands-on cybersecurity and CTF labs focused on **DeathNote**, Linux enumeration, sudo privilege escalation, root-shell exercises, credential discovery, file hunting, and encoded-data analysis.

The collection is useful for cybersecurity students, CTF players, penetration testers, SOC analysts, and security learners who want practical experience with Linux security concepts, privilege escalation workflows, and common encoding techniques.

## Learning Path

A practical progression for this collection is:

1. **Start with enumeration** — practice identifying users, files, services, and useful system information.
2. **Explore credentials and files** — investigate how discovered information can support CTF objectives.
3. **Study sudo security** — understand Linux privilege boundaries and sudo configuration.
4. **Practice privilege escalation concepts** — work through DeathNote and root-focused exercises.
5. **Build decoding skills** — practice Base64, hexadecimal, and other encoded-data analysis.
6. **Combine the skills** — approach complete CTF chains by connecting enumeration, discovery, decoding, and privilege escalation.
